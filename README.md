# Differential-Drive Robot Simulator

> Side project alongside the first 2 months of Thanawya Amma. Pushing progress as I go, so expect incomplete pieces for a while.

## Core components

- differential drive kinematics
- collision detection
- PID control for path following
- A* pathfinding for obstacle-free routing
- simulated range sensors, encoders, and IMU with noise
